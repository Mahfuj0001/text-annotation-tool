# Text Annotation Tool

A lightweight, single-file web tool for labeling text data (sentiment: positive / neutral / negative).

## Features
- Paste any list of sentences, one per line
- One-tap labeling with progress bar and undo
- Export labeled data as CSV or JSON
- Works offline, mobile-friendly, dark mode support
- No dependencies, plain HTML/CSS/JavaScript

## Usage
Open `index.html` in a browser, or host it with GitHub Pages.
